# Contributing

This repository implements a research method and functional demonstrations.

- Keep code, comments, prompts, fixtures, calendar labels, and documentation in English.
- Preserve causal cutoffs, immutable issued forecasts, staged experience updates, and independent experiment banks.
- Add meaningful tests when changing numerical operations, agent tools, memory semantics, or experiment timing.
- Run `python -m pytest -q` and an offline CLI demo before submitting.
- Clearly distinguish offline policies, synthetic data, scripted tests, and live model results.
- Do not commit API keys, `.env`, model weights, runtime artifacts, private data, or generated trajectories.

Changes to the method should describe their assumptions and update the method summary in `README.md`. Keep pull requests focused; UI, hosted services, and ablation studies are outside the current scope.
